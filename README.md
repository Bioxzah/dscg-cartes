# DSCG Cartes

Web app personnelle de révision par répétition espacée pour le DSCG.

- `CLAUDE.md` : instructions pour Claude Code.
- `docs/SPEC.md` : cahier des charges.
- `docs/SETUP.md` : étapes à faire à la main.
- `docs/design-tokens.css` : couleurs et polices, reprises des fiches.
- `cards/` : les cartes, un fichier JSON par chapitre.
